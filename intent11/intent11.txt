The specialized clinic launches a service for 50 remote ultrasound scanners. The sequence of network functions only requires an image collector allocated at the edge and a diagnostic server allocated in the cloud. Among the imposed specifications, the outbound flows from the image collector require encoding. It is mandatory to guarantee a bandwidth from the network gateway to the diagnostic server higher than 500 megabits per second. Furthermore, it is preferred that the image collector runs on a dedicated edge node in isolation.

The industrial provider autoWarehouseOp requires a remote control system for autonomous machines to manage 500 warehouse robots. 
This software receives sensor data, calculates paths to avoid collisions, and sends steering and braking commands. The service chain begins with a sensor 
data decoder allocated at the edge. For this component, decoding is applied after it. The chain then connects to a collision path solver located in the cloud. 
Finally, the system routes to a command encoder allocated at the edge, ensuring that encoding is executed before it. For the entire deployment, it is strictly 
required that the latency from the sensor data decoder to this command encoder remains below 500 ms.

The educational provider eduCloudOp requires a virtual student lab platform to support 10,000 concurrent students. This system provides temporary programming 
environments, manages resource allocation for each student, and monitors the workspaces to prevent improper use. The service chain begins with a session 
ingester allocated at the edge, which handles the initial entry point. Data privacy mechanisms are applied after it. The system then connects to a resource 
allocator located in the cloud, ensuring that the network capacity between the ingester and this allocation unit supports more than 500 mbps. 
The pipeline continues to an activity monitor located in the cloud, ensuring that security controls are executed before it, and that the total response time 
from the session ingester to this monitoring block is kept under 40 ms. The next blocks are a user privacy enforcer located in the cloud and an audit logger 
located in the cloud, where logging operations are executed before the logger. Finally, the system routes the results to an output packager located in the cloud, 
specifying that data compression is applied after it. For the whole deployment, the provider prefers that the aggregate infrastructure footprint stays below 120 gb.

The educational provider eduCloudOp requires a virtual student lab platform to support 10,000 concurrent students. This system provides 
temporary programming environments, manages resource allocation for each student, and monitors the workspaces to prevent improper use. The deployed service 
chain includes, in order: a session ingester allocated at the edge, a resource allocator located in the cloud, an activity monitor located in the cloud, a user 
privacy enforcer located in the cloud, an audit logger located in the cloud, and an output packager located in the cloud. Regarding constraints, data privacy 
mechanisms are applied after the session ingester. To detect anomalies early, security controls are executed before the activity monitor, while ensuring that 
the total response time between the initial session ingester and this security checkpoint is kept under 40 ms. Furthermore, logging operations are executed 
before the audit logger. Data compression is applied after the final output packager. For the network backbone, the provider requires that the capacity between 
the session ingester and the resource allocator supports more than 500 mbps. Finally, the provider prefers that the aggregate infrastructure footprint stays below 120 gb.

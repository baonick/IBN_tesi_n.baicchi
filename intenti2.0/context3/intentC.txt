The website security provider ddosProtectionOp requires an anti-DDoS defense system to handle 50,000 active web users. This system analyzes incoming traffic,
cleans malicious flows, and ensures server availability. Demanding a strictly required bandwidth greater than 500 megabps between them, the service begins
with a traffic analyzer located at the edge linked to a scrubbing filter located in the cloud. Mandating that security is processed before the scrubbing filter, 
the chain then proceeds to a rate limiter located in the cloud. Finally, specifying that logging should ideally be performed after the rate limiter, and preferring 
a latency lower than 10 ms, the system connects to the final web server located in the cloud.

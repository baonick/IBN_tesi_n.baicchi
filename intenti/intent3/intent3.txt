The university universityOp wants to enable virtual reality classrooms for 3000 students. The network functions to be 
instantiated in sequence are a media ingress node at the edge, a virtual classroom server at the edge, and 
a student database in the cloud. Among the expectations, video streams must be decoded before entering the 
classroom server. It is mandatory that the bandwidth from the network gateway to the server exceeds 1000 
megabits per second. Furthermore, it is mandatory that the media ingress node and the virtual classroom 
server are hosted on the exact same physical node.
